EV is estimated from closing-line value: once a closing price is known, your price at wager is compared against it to estimate fair edge before the result is known — the standard way sharp bettors measure skill independent of variance. Type a bet into "Paste a bet confirmation" (e.g. "brunson assists over 6.5 at draftkings +150") to track it automatically — the Update Odds GitHub Action checks sharp books (DraftKings, FanDuel, Novig, Kalshi, Pinnacle, Circa Sports) every 10 minutes, capturing an opening price, a live price that updates until kickoff, and a closing price once the line locks. On the live GitHub Pages URL this page syncs those prices in automatically every couple minutes; CLV%/EV shown before kickoff (marked with ~) use the live price as a provisional stand-in. You set the outcome (won/lost/push/etc.) yourself once the bet settles. It assumes the closing line is single-sided fair value; enter opposing closing odds in Notes if you want to de-vig by hand. All ledger data stays in this browser only (nothing is sent anywhere) — use Export backup regularly, since clearing site data or switching browsers will lose it.
